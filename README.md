# DC Music Love

A music company web app and admin dashboard for artists, releases, events, and media management.

## Stack

- Next.js
- TypeScript
- Tailwind CSS

## Getting started

1. Install dependencies:
   npm install
2. Start the app:
   npm run dev
3. Open http://localhost:3000

## Project structure

- `app/` - App Router pages and layouts
- `components/` - Shared UI components
- `data/` - Mock data for the music company website

## Notes

This starter includes a public-facing website and a basic admin dashboard foundation for DC Music Love.
